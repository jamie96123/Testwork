STM32G474RE / CubeMX + CubeIDE / HAL / Lab1–5

這是可貼入既有專案的完整 USER CODE 應用程式，不是可直接燒錄的 HEX。必須先用 CubeMX 產生下列初始化；不要使用上一版 TIM2 韌體。

01 — 接線與 CubeMX 設定

接腳功能設定
PC8綠 LED · 呼吸燈TIM3_CH3 / AF2
PC9黃 LED · 恆亮TIM3_CH4 / AF2
PC6紅 LED · 恆亮GPIO Output / Push Pull / 初始 Low
PA2 / PA3LPUART1 TX / RXAF12 / 115200 / 8N1 / TX + RX

每顆 LED：腳位 → 獨立 330Ω–1kΩ 電阻 → 正極；負極接 GND。先斷電再接線，無需任何實體按鈕。

  • TIM3 clock 必須確認為 170 MHz；PSC=169，ARR=1999，PWM mode 1，Polarity High，CH3／CH4 初始 Pulse=0。頻率 500 Hz。
  • LPUART1 使用中斷接收，NVIC priority=5。SYS 保留 Serial Wire，SysTick 維持 CubeMX 原設定。
  • CubeMX 產生 hlpuart1、htim3，並先呼叫 MX_GPIO_Init、MX_LPUART1_UART_Init、MX_TIM3_Init。

02 — 將四段內容貼進 main.c

  1. Includes 區段：引入 string.h。
  2. USER CODE BEGIN 0：貼入檔案中完整變數與函式。
  3. USER CODE BEGIN 2：所有 MX 初始化完成後呼叫 Lab_Init();。
  4. while(1) 的 USER CODE BEGIN 3：呼叫 Lab_Task();，不加 HAL_Delay。

程式的四段內容有明確標記。請先備份原專案，移除／合併舊 UART 接收 callback，避免重複定義。不要把程式全部貼到同一區。

03 — 確認 UART 中斷入口

在 stm32g4xx_it.c 的 USER CODE 宣告區加入 handle，並確認以下 IRQ 函式只存在一份。CubeMX 已產生時不重複加入。

extern UART_HandleTypeDef hlpuart1;

void LPUART1_IRQHandler(void)
{
    HAL_UART_IRQHandler(&hlpuart1);
}

Build 後燒錄，再用桌面 Chrome／Edge 連接 ST-LINK Virtual COM Port。網頁收到 OK HELLO 才確認新版韌體；請關閉占用相同 COM 埠的序列埠助手。

綠燈約 2 秒呼吸；暫停改恆亮、繼續恢復呼吸。網頁重置或一局結束會全關。直接拔線或關閉視窗不保證送出關燈指令，必要時按板子 RESET。
